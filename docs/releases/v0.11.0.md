# v0.11.0 — 增量模型发现与元数据故障恢复

v0.11.0 优化 OpenCode 的 LiteLLM 模型刷新：以 `model_name` 作为模型身份，避免每次刷新都重新处理未变化的模型；临时 models.dev 故障造成的 withheld 模型也可在后续刷新中恢复。

## 用户可见变化

- LiteLLM 返回的模型集合未变化时，OpenCode 复用已有 ProviderSnapshot 和注册视图，不重新匹配 models.dev。
- 新增模型优先使用本地 models.dev catalog；只有本地未命中时才请求最新 catalog，并只处理新增模型。
- 如果 catalog 临时不可用导致新模型以 `metadata-unavailable` 状态 withheld，后续刷新会在模型集合不变时重试该模型；已有正常注册模型继续复用。
- 完整 catalog 中稳定的 unmatched/invalid 结果不会因每次刷新而重复请求；成功发现中已删除的模型仍会撤下。

## 升级

无需更改 LiteLLM endpoint、凭据或模型配置。固定安装版本使用 `opencode plugin add github:rpchen/opencode-litellm-provider#v0.11.0`。
