# v0.4.1 — OpenCode multi-endpoint runtime hotfix

v0.4.1 修复 v0.4.0 在 OpenCode 2.x 实机上的 multi-endpoint 运行时兼容问题。

## 修复内容

- 移除不存在的 `context.plugin.add/remove` 动态 child-plugin 调用；该错误会让显式多个 endpoint 的 server plugin 直接进入 `failed`。
- 多个 LiteLLM endpoint 改为在**同一个 OpenCode V2 plugin context** 中注册。
- 每个 endpoint 保持独立 integration/provider identity：
  - `default` → `litellm` / **LiteLLM**
  - `company` → `litellm-company` / **LiteLLM · company**
  - 其他 endpoint 同理。
- `/connect` 可分别选择每个 LiteLLM integration 并保存独立 API Key；显式 endpoint 的 `baseUrl` 已来自插件配置，所以连接时只需填写 Key。
- activation 只启停对应 provider/discovery runtime，不再删除 endpoint integration 或已保存 credential。
- 保留既有 endpoint 隔离：credential、discovery/cache、snapshot、provider state 和故障域仍彼此独立。
- 修复后 `/litellm-endpoints`、`/litellm-diagnostics`、`/litellm-audit-export` 的 server RPC → TUI 卡片链路重新可用。

## 安装与升级

跟随最新稳定分支：

```sh
opencode plugin add github:rpchen/opencode-litellm-provider
```

固定安装 v0.4.1：

```sh
opencode plugin add github:rpchen/opencode-litellm-provider#v0.4.1
```

已有安装升级：

```sh
opencode reload
opencode plugin update "github:rpchen/opencode-litellm-provider"
opencode reload
opencode plugin list
```

如果你使用显式多个 endpoint，升级后再执行 `/connect`，分别选择 **LiteLLM**、**LiteLLM · <endpoint-id>** 配置各自 API Key。
