# v0.2.0 — 共享 discovery core 首个发行版

本版将共享 core 迁移 PR #19 的已验证构建正式提供为固定版本。插件入口、配置、凭据、协议到 SDK 的映射、模型筛选、推理档位、轮询、网络降级、审计和 TUI 的用户行为保持不变。不发布 npm。

## 主要变化

共享的 LiteLLM 元数据处理逻辑只在 `rpchen/litellm-discovery-core` 维护；OpenCode 只保留宿主适配。共享 core 的 ESM、类型声明和许可证已包含在插件 dist 中，安装和运行时不下载 core，不依赖构建缓存、平级仓库或安装生命周期脚本。

更新构建会取得当次 core/main 并固定完整 SHA；固定产物复验和 Release 则只使用已有 provenance，避免主分支前移改变同一版本的构建输入。CI 独立重建并比较原始 dist，覆盖过期/缺失/多余产物和脏缓存风险。

本次发行不重新取得 core/main、不变更已实测的源码和 dist，也不升级依赖。manifest 与 lockfile 的包自身版本统一为 0.2.0。新增发行元数据正负向测试，显式发布入口只接受既有版本 tag；Release 上传后下载附件核验 SHA-256、归档字节和解包 dist。

## 安装与升级

全新安装并跟随 main：

```sh
opencode plugin add github:rpchen/opencode-litellm-provider
```

全新安装并锁定本版本：

```sh
opencode plugin add github:rpchen/opencode-litellm-provider#v0.2.0
```

已有插件时，不要重复追加第二条配置。保留原 `options`，在现有 plugins 条目中将旧 `#v0.1.4` 改为无后缀来源（跟随 main）或 `#v0.2.0`（固定本版本）。`plugin check/update` 的参数必须与配置中的完整来源一致，固定旧 tag 的 `current` 不代表已经与 main 同步。

跟随 main 的现有安装可执行：

```sh
opencode reload
opencode plugin update "github:rpchen/opencode-litellm-provider"
opencode reload
opencode plugin list
```

core 更新不会自动改变已经发布的插件；下一次显式插件更新构建才会包含新 core。Pi 与 core 仓库本次均不修改，不包含跨仓库自动联动。
